# Navneet & Muskan Wedding Website (React)

A React + Vite conversion of the supplied wedding website. It includes the midnight-blue/gold styling, responsive navigation, English/Hindi toggle, falling-petal canvas, event cards, venue/map link, scroll reveal, and live countdown.

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Customize wedding details

Edit `src/config.js` to change the wedding date, venue, ceremony time, event times/places, or default language.

## Images

Copy your existing `hero.png` and `decor.png` into `public/`. They are referenced as `/hero.png` and `/decor.png`.

## Build for production

Run `npm run build`; output is created in `dist/`.
